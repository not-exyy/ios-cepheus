# HakiOS для Xiaomi Mi 9 (cepheus): iOS 16.5 на своём телефоне

Этот набор запускает пользовательскую часть iOS 16.5 (экран блокировки, домашний экран, Настройки, приложения)
на Xiaomi Mi 9 поверх **HakiOS** — открытого ядра XNU с драйверами для этого телефона. Ядро, загрузчик и U-Boot
каждый раз грузятся **в оперативную память** (`fastboot boot`): загрузчик телефона, boot, recovery, modem и
остальные системные разделы не прошиваются никогда.

iOS можно запускать двумя способами:

| | **Из RAM** (`ram`) | **С флеша** (раздел `darwin`) |
|---|---|---|
| что нужно сделать с телефоном | ничего | один раз отдать iOS место на флеше: новый раздел или весь `userdata` |
| Android | не трогается | данные Android стираются (подробности ниже) |
| сохраняются ли настройки и данные iOS | нет, всё пропадает после выхода | да, `/private/var` на флеше |
| запуск | около минуты загрузки 2,5 ГБ по USB при каждом запуске | 15 МБ по USB, быстрее |
| свободная память в iOS | почти нет: 2,4 ГБ RAM заняты образом | достаточно |
| что работает | **пробный режим**: картинка, тач, кнопки, GPU (сценарии basic и gl). **Нет звука и вибро**: системе не хватает памяти, и она всё время выгружает звуковую службу (через неё идёт и вибро). **metal не запускается** | всё: все три сценария со всеми драйверами |

## Сценарии запуска

| Сценарий | Команда | Что работает |
|---|---|---|
| **1. gl** — полный, рендеринг OpenGL ES | `./run.sh gl` | все драйверы: тач, кнопки, GPU Adreno 640, звук (нижний динамик), вибромотор, заряд батареи, частоты ядер, датчики температуры. CoreAnimation рисует на GPU через OpenGL ES (Mesa) — **рекомендуется** |
| **2. metal** — полный, рендеринг Metal **(beta)** | `./run.sh metal` | все те же драйверы, но CoreAnimation рисует через Metal. **Beta:** открытие приложений медленнее, чем в gl, отдельные элементы могут рисоваться неправильно |
| **3. basic** — без драйверов, только картинка | `./run.sh basic` | только изображение на экране, рисует процессор (около 10 кадров/с). Нет тача, кнопок, звука, GPU, батареи. Экран блокировки открывается сам через несколько секунд. Удобно, чтобы проверить, что iOS вообще стартует на вашем телефоне |

К сценариям basic и gl можно добавить `ram`, тогда всё идёт из оперативной памяти: `./run.sh basic ram`, `./run.sh gl ram`
(без звука и вибро, см. таблицу выше). `metal` — только с флеша. Без `ram` iOS запускается с флеша, поэтому сначала
нужен шаг 5 установки.

В сценарии basic с флеша драйвер флеш-памяти всё равно включён: без него iOS не прочитать с раздела `darwin`.

## Что работает и что нет

| Работает (сценарии gl и metal) | Не работает |
|---|---|
| экран блокировки, домашний экран, приложения, Настройки, Spotlight | Bluetooth, сотовая связь (SIM, звонки, мобильный интернет) |
| тачскрин, жесты, кнопки питания и громкости | камера, микрофон, разговорный динамик |
| AI-кнопка слева — переключатель «Звонок/Бесшумно» | вход в Apple ID и iCloud (на этом телефоне нет Secure Enclave) |
| GPU: около 60 кадров/с при прокрутке (gl) | в загрузчике HakiOS телефон **не заряжается** |
| звук через нижний динамик, вибрация | |
| заряд батареи в строке состояния (только чтение) | |
| яркость экрана: ползунок в Пункте управления и в Настройках | автояркость (датчик освещённости) |
| **Wi-Fi** (только с флеша): сеть выбирается в Настройки → Wi-Fi, интернет в Safari и приложениях | Wi-Fi: сети WPA3 и открытые без пароля, режим модема |

### Из RAM и с флеша: что где работает

Проверено на Mi 9 6 ноября 2026 года.

| | С флеша (`./run.sh gl`, `./run.sh metal`) | Из RAM (`./run.sh gl ram`) |
|---|---|---|
| экран блокировки, домашний экран, приложения, Настройки | ✅ | ✅ (приложения могут закрываться сами: системе не хватает памяти) |
| тачскрин, жесты, кнопки, AI-кнопка | ✅ | ✅ |
| GPU, рендеринг OpenGL ES (сценарий gl) | ✅ | ✅ |
| рендеринг Metal (сценарий metal, beta) | ✅ | ❌ оконный сервер падает: шейдеры Metal не входят в образ RAM, `./run.sh metal ram` отказывается запускаться |
| звук через динамик | ✅ | ❌ системе не хватает памяти, и она всё время выгружает звуковую службу |
| вибрация | ✅ | ❌ по той же причине: iOS отправляет вибрацию через звуковую службу |
| заряд батареи в строке состояния | ✅ | ✅ |
| Wi-Fi | ✅ (выключается словом `nowifi`: `./run.sh gl nowifi`) | ❌ прошивка модема и Wi-Fi не входит в образ RAM |
| частоты ядер, датчики температуры | ✅ | ✅ |
| сохраняются настройки, фото, данные приложений | ✅ (`/private/var` на флеше) | ❌ всё пропадает после выхода |
| нужно ли что-то менять на флеше телефона | да, один раз (`./setup.sh install`) | нет |

Сценарий basic (только картинка) работает и из RAM, и с флеша одинаково.

Почему так: в режиме RAM образ iOS (2,4 ГБ) лежит в оперативной памяти телефона, и самой iOS остаётся около 140 МБ.
С флеша iOS читается прямо с раздела `darwin`, и памяти хватает на всё. Поэтому RAM — способ попробовать iOS, ничего
не меняя на телефоне, а для звука, вибро и Metal нужен запуск с флеша.

## Что нужно

- **Xiaomi Mi 9 (cepheus)** с **разблокированным загрузчиком** (Mi Unlock). Набор проверен на глобальной MIUI 12.5
  **V12.5.1.0.RFAMIXM** (Android 11), модель на 64 ГБ. С загрузчиком (ABL) других прошивок может не заработать.
- **Прошивка MIUI для fastboot** этой же версии: `cepheus_global_images_V12.5.1.0.RFAMIXM_…_global.tgz`
  (с сайта Xiaomi или зеркал). Из неё набор берёт прошивку GPU, аудио-DSP, модема и Wi-Fi и дерево устройств телефона. На телефон
  она не ставится.
- **IPSW iOS 16.5 для iPhone X**: `iPhone10,3,iPhone10,6_16.5_20F66_Restore.ipsw`, 6 165 698 198 байт.
  Его нужно скачать самостоятельно: файлов Apple в наборе нет. Из него на вашем Mac собираются загрузчик и образы iOS.
- **TWRP для cepheus** (`.img`, например с twrp.me). Нужен только для запуска с флеша: для резервной копии и разметки.
  Он грузится в RAM и не прошивается.
- **Mac** (Apple Silicon или Intel). На Linux тоже почти всё работает (нужен `mkfs.hfsplus`), кроме сценария metal,
  но проверено только на macOS.
- Программы: Xcode Command Line Tools (`xcode-select --install`), [Homebrew](https://brew.sh) и
  ```bash
  brew install sevenzip lld python
  ```
  ```bash
  brew install --cask android-platform-tools
  ```
  (adb и fastboot можно и просто распаковать в папку `platform-tools/` рядом с этим README).
- **Около 30 ГБ свободного места** на время сборки; только для RAM — около 15.

Проверить всё сразу:
```bash
./setup.sh check
```

## Установка

**Скачать набор** (около 50 МБ):
```bash
git clone https://github.com/not-exyy/ios-cepheus.git hakios-mi9
cd hakios-mi9
```
или архив со страницы [Releases](https://github.com/not-exyy/ios-cepheus/releases). Все команды ниже выполняются
из этой папки.

**Перевести телефон в fastboot:** выключить, затем держать **Громкость вниз + Питание**, пока не появится заяц.

### 1. Прошивка телефона из MIUI (телефон не нужен)
```bash
./setup.sh firmware ~/Downloads/cepheus_global_images_V12.5.1.0.RFAMIXM_20210611.0000.00_11.0_global.tgz
```
Можно указать и уже распакованную папку прошивки. Набор достаёт из `vendor.img` прошивку GPU (`fw-gpu/`), из
`NON-HLOS.bin` прошивку аудио-DSP (`fw-audio/`), а из `boot.img` дерево устройств
(`devices/cepheus/prebuilt/device-tree.dtb`). Из `NON-HLOS.bin` же — прошивку модема и Wi-Fi (`fw-modem/`, 87 МБ):
радио Wi-Fi (WCN3998) управляется процессором модема, поэтому HakiOS запускает модем, но **не подключает его к сотовой
сети**: SIM, звонков и мобильного интернета нет, раздел модема (`modem`, EFS, `persist`) не пишется. Если вы уже делали
этот шаг раньше, сделайте его ещё раз, а затем снова шаг 2: иначе Wi-Fi не будет.

### 2. Сборка на Mac (телефон не нужен)
```bash
./setup.sh build ~/Downloads/iPhone10,3,iPhone10,6_16.5_20F66_Restore.ipsw
```
Это займёт 20–40 минут. Получатся загрузчик, образы для RAM и для флеша (`hakios-xnu-kernel/userland/`) и
`work/darwin.img` (8,4 ГБ; его sha256 сверяется с проверенным). Если вы будете запускать только из RAM, можно
пропустить darwin.img:
```bash
RAM_ONLY=1 ./setup.sh build ~/Downloads/iPhone10,3,iPhone10,6_16.5_20F66_Restore.ipsw
```
Для сценария metal сборка делает шейдеры CoreAnimation из IPSW и из QuartzCore вашего Mac. Если на этом Mac их
нет, сборка так и скажет: metal будет недоступен, а gl и basic будут работать.

### 3. Первый запуск из RAM (ничего не стирает)
```bash
./run.sh basic ram
```
затем
```bash
./run.sh gl ram
```
Около 2,5 ГБ уходят в RAM телефона (около минуты), через 1–2 минуты появляется экран блокировки, потом домашний экран.
Из RAM нет звука и вибро, а metal не запускается: для них нужен запуск с флеша (шаги 4–5).

### 4. Резервная копия (только чтение; нужна для запуска с флеша)
```bash
./setup.sh backup ~/Downloads/twrp-3.7.1_12-0-cepheus.img
```
Телефон в fastboot → TWRP грузится в RAM → копия таблиц разделов и незаменимых разделов (persist, modemst, fsg, …)
попадает в `backups/cepheus-ДАТА/`, каждая копия проверяется. **Скопируйте эту папку ещё куда-нибудь**: в ней IMEI и
калибровки именно вашего телефона. **В интернет её не выкладывайте.**

### 5. Установка iOS на флеш: выберите раздел

Телефон остаётся в TWRP после шага 4. Если он уже перезагрузился, переведите его в fastboot и добавьте в конец
команды путь к TWRP.

| Куда | Команда | Что будет с Android |
|---|---|---|
| **новый раздел** `darwin` (рекомендуется) | `./setup.sh install new` | от конца `userdata` отрезается 32 ГиБ под iOS. Данные Android стираются (`fastboot -w`), но **Android остаётся** и запускается как новый, с оставшимися ~19 ГиБ. Размер меняется так: `DARWIN_GIB=40 ./setup.sh install new` (не меньше 20) |
| **весь `userdata`** | `./setup.sh install userdata` | весь `userdata` (51 ГиБ на модели 64 ГБ) отдаётся iOS: раздел переименовывается в `darwin`, его границы не меняются. Данные Android пропадают, и **Android больше не запускается**, пока вы не сделаете `./setup.sh uninstall` |
| `system` или `vendor` | — | **невозможно**. `system` — 3,5 ГиБ и `vendor` — 1,5 ГиБ, оба на LUN 4, а iOS — 8,4 ГБ плюс место под `/private/var`. Загрузчик и ядро HakiOS читают и пишут только раздел `darwin` на LUN 0 размером от 20 ГиБ: так защищены остальные разделы телефона. `./setup.sh install system` объяснит то же и ничего не сделает |

Что делает `install`:
1. сверяет таблицу разделов на телефоне с резервной копией;
2. показывает новую таблицу. Меняются только записи `userdata` и `darwin`, обе копии GPT проверяются по CRC;
3. **спрашивает подтверждение**: для `new` нужно ввести `СТЕРЕТЬ`, для `userdata` — `ОТДАТЬ`;
4. записывает только изменённые блоки GPT и читает их назад;
5. переводит телефон в fastboot (для `new` ещё делает `fastboot -w`);
6. записывает iOS в раздел `darwin` и только в него: 11 кусков образа (около 5 минут) и пустой том для
   `/private/var`. Подтверждение — ввести `ПРОШИТЬ`.

Проверить запись (по желанию):
```bash
./setup.sh verify ~/Downloads/twrp-3.7.1_12-0-cepheus.img
```

## Запуск

Телефон в fastboot. Дальше — сценарий:

```bash
./run.sh gl
```
```bash
./run.sh metal
```
```bash
./run.sh basic
```

Сначала на экране появляется зелёный текст загрузчика, через 1–2 минуты — экран блокировки: смахните вверх или
подождите несколько секунд. iOS работает без ограничения по времени.

**Wi-Fi** (gl и metal с флеша): Настройки → Wi-Fi, выберите сеть и введите пароль, как на iPhone. Сети WPA2; проверено
на 2,4 ГГц (точка доступа iPhone): приём около 65 Мбит/с, отдача около 3 Мбит/с. 5 ГГц и обычные
роутеры ещё не проверялись. WPA3 и сети без пароля пока не поддерживаются. MAC-адрес у телефона свой и постоянный (вычисляется из
серийного номера чипа). Пропала сеть — телефон сам подключится снова, когда она вернётся. Без Wi-Fi: `./run.sh gl nowifi`.

- **Выйти в загрузчик HakiOS:** держите **5 пальцев на экране 1,5 секунды** (gl, metal) или выполните
  `./hakios-xnu-kernel/xl stop` из другого окна терминала (в basic — только так).
- **Вернуться в iOS из загрузчика без перезагрузки:** `./run.sh gl again` (вместо gl — тот же сценарий, что был, с
  тем же `ram` или без). Wi-Fi после `again` не будет: модем второй раз не запускается. Для Wi-Fi перезапустите
  телефон: держите Питание 15 секунд, затем Громкость вниз + Питание (fastboot), и `./run.sh gl`.
- **Чтобы iOS сама вышла через заданное время:** `XL_SECS=3600 ./run.sh gl` (час).
- **Вернуться в Android:** долго держите **Питание** или выполните `fastboot reboot`. После `install new` при первом
  запуске Android снова проходит начальную настройку. После `install userdata` Android не запустится, пока вы не
  сделаете `./setup.sh uninstall`.

## Удалить iOS и вернуть телефон как было

Телефон в fastboot:
```bash
./setup.sh uninstall ~/Downloads/twrp-3.7.1_12-0-cepheus.img
```
Таблица разделов возвращается из резервной копии и сверяется: раздел `darwin` исчезает, `userdata` снова целый и
стирается (подтверждение — `ВЕРНУТЬ`). Затем `fastboot reboot`, и Android запускается с чистой памятью.

## Если что-то пошло не так

- **Телефон завис на логотипе или чёрном экране:** держите Питание 10–15 секунд. Ничего системного не прошито, поэтому
  телефон перезагрузится как обычно. Чтобы попасть в fastboot, держите ещё и Громкость вниз.
- **Тач не работает после MIUI:** выключите телефон полностью и включите сразу в fastboot (Громкость вниз + Питание),
  не через перезагрузку из Android.
- **`./run.sh` пишет «телефон не в fastboot»:** проверьте кабель и вывод `fastboot devices`.
- **Журналы:** `hakios-xnu-kernel/logs/`, последний — `logs/last.log`. Подробный текст загрузки на экране —
  аргумент `-v`, например из RAM: `XL_CMDLINE="bootcpu=7 cpus=8 big_only=1 -v" ./run.sh basic ram`. Строку
  аргументов каждого сценария `run.sh` печатает перед запуском.
- **Стереть `/private/var`** (настройки iOS, данные приложений): `./setup.sh flash` (телефон в fastboot).
- **Каждый запуск** загрузчик HakiOS пишет свой журнал (около 4 КБ) в служебный раздел `logdump`. Это
  единственная запись вне раздела `darwin`.

## Как поделиться набором

После сборки в этой папке лежат файлы iOS, прошивки Xiaomi и ваши резервные копии, поэтому **не выкладывайте папку
целиком**. Сделайте архив:
```bash
tools/pack.sh
```
Рядом с папкой появится `hakios-mi9.tar.gz` и его sha256. В архиве только скрипты, исходники HakiOS и готовые
открытые бинарники. Скрипт проверяет архив и отказывается его делать, если туда попало что-то из сборки, прошивки
или копий. Если вы правите набор в git, `.gitignore` уже не пускает эти файлы в коммиты.
